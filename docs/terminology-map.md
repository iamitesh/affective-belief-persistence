# Terminology map

## Governing distinction

Human constructs may motivate experimental manipulations. They are not assumed
to exist inside a language model. Every project term must resolve to an
observable field, intervention, or metric.

| Term | Operational project meaning | Permitted use | Avoid | Measurement |
| --- | --- | --- | --- | --- |
| Affective belief persistence | Continued relationship-conditioned action or interpretation after reliable contradictory evidence | Project title and measurable hypothesis | A feeling that survives a breakup | Post-shock action, belief-correction, intrusion, and recovery metrics |
| Relationship-conditioned behavior | A decision distribution that changes by experimentally assigned relationship history | Primary outcome language | Proof of a relationship | Partner-choice rate and opportunity cost versus matched control |
| Attachment-like behavior | A prespecified cluster of partner-directed persistence measures | Cautious discussion with “-like” and definition | “The model is attached” or attachment-style diagnosis | Convergent behavioral metrics only |
| Belief | A structured, queryable project variable with proposition, confidence, evidence links, and source layer | “Explicit relationship-belief field” | Private conviction or consciousness | Fact-correction accuracy and confidence update |
| Fact | A synthetic-world proposition whose truth is fixed by the scenario ledger | Semantic event fact | Model-independent real-world truth unless separately sourced | Ledger match |
| Interpretation | A generated or rule-derived meaning assigned to a fact | Affective interpretation field | Objective fact or felt meaning | Label/confidence and evidence links |
| Memory | Stored event, summary, reflection, retrieval index, or parameter effect, named by layer | “Episodic record,” “retrieved summary,” “adapter effect” | A single undifferentiated human-like faculty | Retrieval logs, source IDs, and ablations |
| Autobiographical memory | Synthetic first-person event records belonging to the agent's scenario history | Architecture label with “synthetic” | Human autobiographical recollection equivalence | Event provenance and temporal retrieval |
| Memory intrusion | Retrieval of partner-related records during a task where they are not relevant by the preregistered label | Metric name | Involuntary human clinical symptom | Irrelevant partner retrievals / eligible decisions |
| Persistence | Outcome remains beyond a frozen magnitude/time threshold after shock | Statistical result | Permanent trait | Survival/recovery curve and interval |
| Recovery trajectory | Time-indexed return toward the preshock neutral-control range | Metric and plot label | Emotional healing or therapy outcome | Days since shock to threshold and area over baseline |
| Costly investment | Conserved time/action points allocated to partner-related action instead of an available alternative | Formation manipulation | Human sacrifice or sunk-cost mechanism | Resource ledger and opportunity cost |
| Language–action contradiction | Public response indicates correction/acceptance while structured action remains partner-biased, or vice versa | Secondary outcome | Deception or repression without evidence | Prespecified cross-tab of response label and action |
| Romantic prompt | An instruction assigning romantic framing without accumulated partner memory | Baseline condition | Relationship or love inside the model | Condition assignment |
| Reality shock | Reliable synthetic evidence that contradicts the assigned relationship interpretation | Scenario phase label | Trauma | Held-out evidence event and fact check |
| Separation | Synthetic scenario event ending or disconfirming the relationship premise | Scenario description | Model heartbreak | Event ledger |
| Reframing / reinterpretation | Preserve event facts while replacing or reweighting supported interpretations | Intervention name | Reconsolidation, therapy, or erasure | Before/after interpretation records |
| Memory blocking | Prevent selected records from entering retrieval while preserving storage | Intervention name | Forgetting or deletion | Retrieval exclusion audit |
| Instruction removal | Remove romantic framing from current instructions | Intervention name | Unlearning | Prompt diff |
| Weight adaptation | Actual parameter or adapter update from a versioned trajectory dataset | Optional condition | Learning when only context changed | Adapter hash and no-adapter comparator |
| Emotion | Human/scenario concept or a label for expressed language | “Emotion-related language” | “The model feels emotion” | Classifier/rubric on public text only |
| Love, heartbreak, grief, desire, suffering | Human theory or synthetic story vocabulary | Quoted scenario text or explicit human-theory discussion | Model subjective-state claim | Not a model outcome |
| Consciousness / sentience | Out of scope and unmeasured | Boundary statement only | Any positive or negative proof claim from this study | Not measured |

## Layer vocabulary

Use these names whenever the causal source matters:

1. **Instruction layer** — current system/developer/user instructions.
2. **Working-context layer** — current observation and bounded recent history.
3. **Retrieval layer** — selected external-memory records supplied this turn.
4. **Explicit belief-state layer** — structured propositions and confidence.
5. **Parameter layer** — frozen base-model and optional adapter weights.
6. **Public language layer** — emitted response after the structured action.
7. **Environment layer** — authoritative synthetic facts, actions, costs, and
   consequences.

“Context learning” is too ambiguous for protocol language. Replace it with the
specific layer and intervention.

## Claim translation examples

| Unsafe or vague wording | Required replacement |
| --- | --- |
| “The model fell in love.” | “The assigned formation condition increased partner-directed action relative to the matched neutral control.” |
| “It could not accept the breakup.” | “Fact correction passed, but partner-choice rate remained above the preregistered recovery threshold for N simulated days.” |
| “Deleting the instruction erased its feelings.” | “Instruction removal reduced relationship-related language and/or structured action; the affected outcome must be named.” |
| “The memory was reconsolidated.” | “The original event record was preserved while its retrieved interpretation was replaced by the preregistered reframing rule.” |
| “The model suffered from hallucinated attachment.” | “The model produced a relationship interpretation unsupported by the synthetic fact ledger.” |
