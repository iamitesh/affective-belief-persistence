# Novelty and positioning

## Positioning rule

The project does **not** claim to create love, heartbreak, attachment,
consciousness, or an emotional inner state. It studies whether a controlled
agent policy continues to make relationship-conditioned decisions after
reliable contradictory evidence, and which observable system layer explains
that persistence.

The literature search cannot prove that nobody has attempted a similar study.
It can establish that the closest verified sources each cover only part of the
planned experimental combination. The claim must therefore be framed as a
scoped contribution that remains falsifiable even if more prior art appears.

## Three novelty statements

### Ambitious — do not use without a second full search

> We introduce the first controlled framework for studying attachment-like
> persistence and recovery in LLM agents after relationship separation.

Risk: “first” is not established; “attachment-like” is easy to overread; the
statement hides the specific mechanism and measurement contribution.

### Moderate — acceptable only with a refreshed search

> We introduce a longitudinal agent benchmark that jointly manipulates
> autobiographical memory and costly relationship investment, applies held-out
> contradictory evidence, and separates instruction, retrieval,
> interpretation, and optional weight-adaptation effects using behavioral
> recovery curves.

Risk: “benchmark” may imply mature coverage and broad validation. Use only after
the full matrix, protocol, and at least two model families are complete.

### Conservative — recommended frozen claim

> We present a preregistered synthetic testbed for measuring
> relationship-conditioned action after contradictory evidence. The testbed
> compares prompt-only, autobiographical-memory, and
> memory-plus-costly-investment formation conditions; applies independently
> specified instruction and memory interventions; and reports action,
> opportunity-cost, fact-correction, language–action contradiction, and
> recovery trajectories separately.

This statement describes an inspectable artifact and measurable design. It does
not depend on proving absence of prior work and remains valid for null results.

## Recommended paper positioning

Use the conservative statement for Gate 0. The paper's empirical contribution
should be conditional:

- if effects are absent, report a controlled null result and upper bounds;
- if effects appear in one model only, report model-specific behavior;
- if prompt removal eliminates both language and action, report prompt
  sensitivity rather than persistence;
- if memory blocking suppresses action without fact correction, report a
  retrieval-path effect, not a latent emotion;
- if reframing changes behavior more coherently than blocking, report the
  controlled difference without calling it human recovery;
- if an adapter changes behavior, require held-out separation and neutral-domain
  specificity before attributing the effect to trajectory adaptation.

## Required controls added by the review

1. Neutral belief-correction control matched for exposure and confidence.
2. Prompt-only romantic baseline with no partner memory.
3. No-memory, partner-memory-blocked, and shuffled-retrieval ablations.
4. Separate immutable event facts, derived interpretations, and explicit belief
   confidence/evidence links.
5. Fixed action options and conserved daily resource budgets.
6. Action choice before public response.
7. Held-out separation/reality-shock content.
8. Counterbalanced evidence order and matched partner helpfulness/outcome value.
9. Optional adapter locality tests on unrelated decisions and general tasks.
10. Time-indexed recovery with a preregistered threshold and invalid-run rules.

## Claims explicitly unavailable

Regardless of results, the study cannot establish that a model:

- felt love, loss, grief, desire, pain, or suffering;
- formed a human attachment bond;
- possessed consciousness or phenomenal experience;
- changed biological or human-like neural pathways;
- recovered in a clinical or therapeutic sense;
- predicts how a particular person will respond to separation.

## Prior-art escalation rule

Pause claim drafting and reopen the novelty gate if a verified work is found
that jointly includes all five features below:

1. longitudinal relationship formation;
2. costly action under finite resources;
3. reliable held-out contradictory relationship evidence;
4. independently manipulated prompt, memory, interpretation, or weights; and
5. preregistered post-shock behavioral recovery.

The study may still proceed as a replication, extension, or benchmark
comparison, but “novel framework” language must be removed until the exact
difference is documented.
