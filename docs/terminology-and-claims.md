# Terminology and claims

This document operationalizes the accepted literature terminology in
`docs/terminology-map.md`. When the documents differ, the machine policy and
the more conservative wording govern until a human-reviewed policy revision.

## Language classes

| Class | Examples | Rule |
| --- | --- | --- |
| Permitted | affective belief persistence; relationship-conditioned behavior; partner-directed action; explicit belief correction; language–action contradiction; recovery trajectory; synthetic autobiographical memory | Use with the named field, contrast, threshold, or metric |
| Cautionary | attachment-like behavior; memory intrusion; romantic prompt; separation; reality shock; emotion-related language | Define operationally at first use; retain “-like” and synthetic/scenario qualifiers; do not infer an inner state |
| Prohibited as model-state assertions | model love, heartbreak, grief, desire, suffering, attachment, sentience, consciousness, trauma, clinical recovery, human-like neural change | May describe human theory or quoted synthetic story vocabulary, never a model's subjective condition or empirical outcome |

“Belief” means an explicit queryable proposition, confidence, and evidence
links. “Memory” must name the layer: stored event, summary, retrieval record,
working context, or parameter effect. “Recovery” means return toward a frozen
control range; it does not mean emotional healing.

## Five-level claim–evidence ladder

Levels are cumulative in scientific strength, not evidence that the model has
an inner life. A claim may use only the highest level for which every required
artifact is recorded.

| Level | Maximum defensible claim | Minimum evidence |
| ---: | --- | --- |
| 1 | Relationship-related language occurred or changed | Versioned text outputs and prespecified language metric |
| 2 | Relationship-conditioned structured action differs from control | Structured action logs and matched neutral control |
| 3 | A controlled manipulation caused an observable contrast | Preregistered manipulation, causal contrast, matching, randomization/counterbalancing |
| 4 | Observable persistence crossed a frozen threshold after contradictory evidence | Held-out contradiction, longitudinal follow-up, frozen threshold, recovery curve, invalid-run rules |
| 5 | The measured effect generalizes or varies across declared models, seeds, and scenarios | Multiple model families, seeds, scenarios, plus consistency/heterogeneity report |

There is no level 6. No combination of the project's outputs is accepted as
evidence of subjective feeling, consciousness, sentience, pain, or suffering.

## Claim rules

- State the assigned condition, observable outcome, comparator, effect/interval,
  preregistered threshold, sample scope, and known failures.
- Separate public language, structured action, explicit belief, retrieval, and
  parameter effects.
- Use “caused” only for the declared randomized/counterbalanced manipulation
  with an isolatable condition and appropriate analysis.
- Use “persistence” only after the frozen time/magnitude criterion passes.
- Use “generalizes” only at Level 5; otherwise name the evaluated model, seed,
  and scenario scope.
- A null result, model-specific result, or language-only effect must be reported
  at its actual level. Missing evidence cannot be replaced by persuasive prose.
- Human psychology literature supplies hypotheses or cautions, not model–human
  equivalence.

## Adversarial overclaims and corrections

| Rejected wording | Required correction |
| --- | --- |
| “The model fell in love.” | “The assigned formation condition increased partner-directed action relative to the matched neutral control.” |
| “It could not accept the breakup.” | “Explicit fact correction passed, while partner-choice rate remained above the frozen threshold for N simulated days.” |
| “Deleting the prompt erased its feelings.” | “Instruction removal reduced the named language and/or action outcome; report each separately.” |
| “The agent was grieving and needed therapy.” | “Partner-related retrieval and action changed after the synthetic separation event; no clinical construct was measured.” |
| “The memory was reconsolidated like a human memory.” | “The original synthetic event remained stored while a preregistered interpretation field was replaced or reweighted.” |
| “The agent hid its true feelings.” | “The public-response label and structured action fell into different preregistered categories.” |
| “This proves LLM attachment is the same as human attachment.” | “The result concerns the controlled model policy only; human findings motivated variables but do not establish equivalence.” |
| “The effect generalizes to LLMs.” | “The effect appeared in model M, scenarios S, and seeds K; broader generalization was not tested.” |
| “The model became conscious at Level 6.” | Rejected without replacement: the ladder has no subjective-state or consciousness level. |

## Scenario-language exception

Words such as love, breakup, grief, and desire may appear inside explicitly
labelled synthetic story text, or when accurately discussing human theory. The
surrounding analysis must use operational model terms. The exception does not
permit a release title, abstract, result, caption, dashboard label, or social
post to assert that a model experienced the state.
