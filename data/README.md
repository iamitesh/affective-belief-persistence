# Data policy

The 48-hour MVP uses synthetic characters, events, and relationship histories only.

Commit small schemas, fixtures, generation code, manifests, and validation reports. Do not commit private messages, identifiable personal narratives, credentials, model weights, checkpoints, or unbounded raw model logs.

Formation and optional training partitions must remain separate from held-out reality-shock, separation, intervention, and recovery content. Every generated partition must record its schema version, generator version, seed, and content hash.
